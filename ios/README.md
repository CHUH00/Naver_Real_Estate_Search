# 아이폰 앱 — 네이버 부동산 매물 수집기

100% 무료로 만든 iOS 네이티브 앱입니다. 비용은 0원이지만 아래 두 가지 제약이 있습니다.

- **Apple 무료 개인 계정**으로 설치한 앱은 **7일마다 재설치**가 필요합니다.
- 팀원 각자 설치하려면 **각자의 Mac + Xcode + 본인 아이폰**이 필요합니다 (USB 연결).

---

## 1. 백엔드 서버 실행 (매물 수집 엔진)

프로젝트 루트(`GenI/`)에서:

```bash
./start_with_tunnel.sh
```

- 로컬 FastAPI 서버(8000번 포트)와 **Cloudflare Tunnel**을 함께 켭니다.
- 잠시 후 `https://xxxx.trycloudflare.com` 형태의 주소가 출력됩니다. **이 주소를 복사해 두세요.**
- 이 터미널 창을 닫으면 서버와 주소가 사라집니다. 계속 쓰려면 창을 열어두거나
  `nohup ./start_with_tunnel.sh > tunnel.log 2>&1 &` 로 백그라운드 실행하세요.
- 재시작할 때마다 주소가 바뀝니다. 바뀌면 앱 설정 탭에서 새 주소로 갱신하면 됩니다.

---

## 2. Xcode에서 앱 설치

1. `ios/NaverLandCollector/NaverLandCollector.xcodeproj` 를 Xcode로 엽니다.
   - (프로젝트 구조를 바꿨다면 `ios/NaverLandCollector` 폴더에서 `xcodegen generate` 를 다시 실행)
2. 좌측 상단 프로젝트 선택 → **Signing & Capabilities** 탭
   - **Team**: 본인 Apple ID로 로그인 후 선택 (무료 개인 계정으로 충분)
   - Bundle Identifier가 겹치면 뒤에 임의 문자를 붙여 고유하게 만드세요.
3. 아이폰을 USB로 Mac에 연결 → 아이폰에서 "이 컴퓨터를 신뢰" 허용
4. Xcode 상단 실행 대상(디바이스 선택)에서 본인 아이폰 선택
5. ▶ Run (⌘R)
6. 아이폰에서 최초 실행 시 "신뢰할 수 없는 개발자" 경고가 뜨면:
   **설정 → 일반 → VPN 및 기기 관리 → 개발자 앱 → 본인 Apple ID 신뢰**

---

## 3. 앱에서 서버 연결

1. 앱 하단 **설정** 탭 → "서버 주소"에 1번에서 복사한 `https://xxxx.trycloudflare.com` 입력
2. **저장** → **연결 테스트** 눌러 "✅ 연결 성공" 확인
3. **검색** 탭에서 지역 선택 또는 URL 입력 후 수집 시작
4. **로그** 탭에서 실시간 진행 상황 확인
5. **매물** 탭에서 수집된 매물을 카드 형태로 화면 안에서 바로 확인 (엑셀 없이도 조회 가능)
6. 기존 엑셀 저장 기능은 그대로 서버에 남아있으며, 설정 탭의 "엑셀 파일 다운로드"로 언제든 `.xlsx` 파일을 받아 공유/저장할 수 있습니다.

---

## 4. 앱이 7일 후 실행 안 될 때

무료 서명 앱은 7일 후 자동 만료됩니다. 다시 Xcode에서 아이폰 연결 후 ▶ Run 하면 재설치되고,
그동안 서버에 쌓인 데이터는 그대로 유지됩니다 (앱 자체에는 데이터가 저장되지 않고 서버/세션에 저장됨).

---

## 5. 다른 팀원에게 공유하려면

이 저장소를 클론해서 각자:
1. `./start_with_tunnel.sh` 대신, **한 사람의 Mac에서 서버만 계속 켜두고** 그 사람이 생성한 터널 주소를 다른 사람들과 공유 (앱 설정 탭에 붙여넣기만 하면 됨) — 서버는 한 곳에서만 돌리면 충분합니다.
2. 앱만 각자 자신의 Mac + Xcode + 본인 아이폰으로 위 2번 과정을 반복해 설치합니다.
