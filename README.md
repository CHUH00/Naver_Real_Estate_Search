# 네이버 부동산 매물 수집기

네이버 부동산의 **전세안고 매매** 매물을 자동으로 수집해서 Excel 파일로 저장하는 도구입니다.  
지역명(구/동)으로 일괄 검색하거나, 매물 URL을 직접 붙여넣어 저장할 수 있습니다.

---

## 필요 환경

- **Python 3.10 이상** (3.11 ~ 3.13 권장)
- macOS / Windows / Linux 모두 지원
- 인터넷 연결 필요

---

## 설치 방법

### 1. Python 설치 확인

터미널(맥) 또는 명령 프롬프트(윈도우)를 열고 아래를 입력합니다.

```bash
python3 --version
```

`Python 3.10.x` 이상이 출력되면 정상입니다.  
설치가 안 되어 있다면 [python.org](https://www.python.org/downloads/) 에서 다운로드 하세요.

---

### 2. 파일 다운로드

이 저장소(폴더)를 다운로드하거나 클론합니다.

```bash
git clone <저장소_주소>
cd GenI
```

또는 ZIP으로 다운받은 경우 압축을 풀고 해당 폴더로 이동합니다.

---

### 3. 패키지 설치

아래 명령어를 **한 번만** 실행하면 됩니다.

```bash
pip3 install requests openpyxl playwright
```

설치 후 **Playwright 브라우저**도 한 번 설치해야 합니다.

```bash
python3 -m playwright install chromium
```

> ⚠️ `pip3`가 없으면 `pip`로 시도하세요.  
> ⚠️ Windows에서는 `python3` 대신 `python`을 사용할 수 있습니다.

## 화면 구성 및 사용법

### 지역 일괄 검색

1. 상단 **구 버튼**을 클릭해 검색할 구를 선택합니다 (복수 선택 가능).
2. 구를 클릭하면 해당 구의 **동 목록**이 나타납니다. 동을 선택하면 동 단위로 검색됩니다.
3. **필터 설정** 영역에서 매매가·전용면적·입주가능일·방향 조건을 설정합니다 (비워두면 제한 없음).
4. **검색 시작** 버튼을 클릭합니다.
5. 수집이 완료되면 지정한 Excel 파일에 자동 저장됩니다.

> - 동을 선택하면 동 단위로, 구만 선택하면 구 전체를 검색합니다.
> - 아무것도 선택하지 않으면 직접 입력창에 지역명을 입력할 수 있습니다.

### URL 직접 입력

1. 네이버 부동산에서 수집하고 싶은 매물 페이지를 엽니다.
2. 브라우저 주소창의 URL을 복사합니다.
3. 앱 하단 **매물 URL** 입력창에 붙여넣기합니다.
   - **붙여넣기 버튼** 클릭 시 중복 URL은 자동으로 건너뜁니다.
   - 여러 개는 줄바꿈으로 구분됩니다.
4. **저장하기** 버튼을 클릭합니다.

### 저장 위치

- 기본 저장 파일: 실행 폴더 안의 `네이버_부동산_매물.xlsx`
- **변경** 버튼: 기존 파일에 이어 저장할 위치를 변경합니다.
- **새파일** 버튼: 날짜가 붙은 새 파일을 만들어 저장합니다.
- **엑셀 열기** 버튼: 현재 저장된 파일을 바로 엽니다.

## 필터 설정

검색 전 조건을 걸어 원하는 매물만 저장할 수 있습니다.

| 필터 | 설명 |
|---|---|
| 매매가 | 억 단위로 최소·최대 입력 (예: `8` ~ `16`) |
| 전용면적 | ㎡ 단위로 최소·최대 입력 (예: `84` 이상) |
| 입주가능일 | `년 월` 입력 시 해당 월 이후 입주 가능한 매물만 수집 |
| 방향 | 버튼 클릭으로 원하는 방향 선택 (미선택 시 전체) |

> 즉시입주 · 협의가능 매물은 입주가능일 필터를 항상 통과합니다.

## 자주 묻는 문제

**Q. `ModuleNotFoundError: No module named 'playwright'` 오류가 납니다.**  
A. 패키지 설치 단계를 다시 실행하세요.
```bash
pip3 install playwright
python3 -m playwright install chromium
```

**Q. 수집 중 브라우저 창이 잠깐 뜨고 닫힙니다.**  
A. 정상 동작입니다. 네이버 인증 토큰을 얻기 위해 내부적으로 브라우저를 한 번 실행합니다.

**Q. 수집 결과가 0건입니다.**  
A. 해당 지역에 전세안고 매매 매물이 없거나, 지역명이 정확하지 않은 경우입니다.  
구 칩 버튼을 이용하거나 직접 입력창에 정확한 동 이름을 입력해 보세요.

**Q. Windows에서 `tkinter` 관련 오류가 납니다.**  
A. Python 공식 설치 프로그램으로 재설치할 때 **"tcl/tk and IDLE"** 항목을 체크해야 합니다.
